# Свадебное приглашение — Чынгыз & Айдай

Статический сайт на HTML, CSS и JavaScript. Нет backend, базы данных, регистрации гостей или платных библиотек.

## Файлы

- `index.html` — содержимое сайта.
- `styles.css` — адаптивный минималистичный дизайн.
- `script.js` — обратный отсчёт, анимация появления, управление музыкой.
- `music.mp3` — добавьте свой аудиофайл, если хотите фоновую музыку. Этот файл намеренно не включён: используйте музыку, на которую у вас есть права.

## Перед публикацией

1. Откройте `index.html` и проверьте имена, дату и адрес.
2. В `script.js` обратный отсчёт сейчас ведётся до начала даты 5 декабря 2026 года по времени Бишкека (UTC+6). Если известно время церемонии, замените `2026-12-05T00:00:00+06:00` на нужное время, например `2026-12-05T16:00:00+06:00`.
3. Чтобы музыка работала, положите файл `music.mp3` в ту же папку, что и `index.html`. Рекомендуется короткая инструментальная композиция в MP3, которую разрешено использовать. Без файла сайт продолжит работать, но музыка не включится.
4. Google Fonts подключаются через интернет. При отсутствии интернета сайт использует системные шрифты.

## Публикация через GitHub Pages бесплатно

1. Создайте аккаунт на https://github.com/, если его ещё нет.
2. Нажмите `+` → `New repository`.
3. Назовите репозиторий, например `wedding-invitation`. Для простоты выберите `Public`, затем `Create repository`.
4. В репозитории нажмите `Add file` → `Upload files`.
5. Загрузите `index.html`, `styles.css`, `script.js` и, если добавили музыку, `music.mp3`. Файлы должны лежать в корне репозитория, не во вложенной папке.
6. Нажмите `Commit changes`.
7. Откройте `Settings` → `Pages`.
8. В разделе `Build and deployment` выберите `Deploy from a branch`.
9. В `Branch` выберите `main`, папку `/ (root)` и нажмите `Save`.
10. Подождите несколько минут. На странице `Settings` → `Pages` появится ссылка, обычно вида `https://ВАШ-ЛОГИН.github.io/wedding-invitation/`.
11. Откройте ссылку на телефоне и проверьте кнопку карты и музыку. Музыка запускается только после нажатия пользователя — это ожидаемое поведение браузеров.

## Изменения позже

Измените нужный файл на GitHub через значок карандаша или загрузите обновлённый файл. После `Commit changes` GitHub Pages автоматически обновит опубликованный сайт.

## Важно

- GitHub Pages — публичный хостинг. Не добавляйте сюда личные документы или приватные данные.
- Ссылка на Google Maps открывает поиск по названию и адресу. Перед отправкой гостям проверьте, что она ведёт к нужному месту.
- GitHub Pages предоставляет адрес на домене `github.io`; собственный домен не требуется.
